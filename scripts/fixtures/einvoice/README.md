# E-invoice validation fixtures

`care-suite-{S,Z,E,AE,O,annex}.xml` were generated by the application's UBL serializer in issue mode from explicitly fictional names, addresses, emails and invoice data. They cover standard VAT, zero rate, exemption, reverse charge, outside-scope VAT and an embedded proof attachment. They contain no production records. The example IBAN is test data and is never used for a payment.

`kosit-01.01a-{ubl,cii}.xml` are original public KoSIT test-suite examples from commit `1ce1dafffd035e5ce59a7ab0d3bf44ac14af16c9` of <https://github.com/itplr-kosit/xrechnung-testsuite>, paths:

- `src/test/business-cases/standard/01.01a-INVOICE_ubl.xml`
- `src/test/business-cases/standard/01.01a-INVOICE_uncefact.xml`

The mirrored official repository identifies its authoritative upstream as <https://projekte.kosit.org/xrechnung/xrechnung-testsuite>. Its Apache-2.0 license is included as `LICENSE-KoSIT.txt`. No field in these original fixtures was edited. Their missing performance-period informational finding is deliberately preserved. Generated derivative negative cases are created in memory by the verification script.

`kosit-oracle-results.json` records the independent original Java KoSIT 1.6.3 comparison, binding each input by SHA-256 and recording the actual official findings. This is a regression baseline, not a replacement for running the actual production validation engine.
